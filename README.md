# 筋トレ記録ページ

Codexを使って作成した、自己紹介と筋トレの記録ができるシンプルなWebページです。

## このページでできること

- 筋トレを行った回数を1回ずつ記録できます。
- 今月の目標である12回に対する進み具合を確認できます。
- 目標を達成すると、お祝いのメッセージが表示されます。
- 応援メッセージを表示し、見た回数を確認できます。
- 応援を見た回数は、確認メッセージ付きで0回に戻せます。

## 使い方

1. `index.html`をブラウザで開きます。
2. 筋トレを行ったら、「筋トレを1回記録する」を押します。
3. 「今日の応援を見る」を押すと、応援メッセージが表示されます。
4. 応援回数を0回に戻すときは、「応援を見た回数を0回に戻す」を押します。

## 保存されるデータ

このページは、ブラウザの`localStorage`を使って次の情報を保存します。

- 筋トレの記録回数
- 応援メッセージを見た回数

保存された情報は、このパソコンのこのブラウザ内だけに保存されます。別のパソコンや別のブラウザには自動で共有されません。

## Gitでの基本的な確認方法

変更があるか確認するには、次を実行します。

```bash
git status
```

変更内容を確認するには、次を実行します。

```bash
git diff
```

保存済みの履歴を確認するには、次を実行します。

```bash
git log --oneline
```
