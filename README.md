# 筋トレ記録ページ

Codexを使って作成した、自己紹介と筋トレの記録ができるシンプルなWebページです。

## このページでできること

- 筋トレを行った回数を1回ずつ記録できます。
- 今月の目標回数を自分で変更し、進捗バーと達成率で進み具合を確認できます。
- 筋トレを記録した日付と、その日の記録回数を一覧で確認できます。
- 今日の筋トレ記録を1回取り消せます。
- 今月の筋トレ回数と日付一覧をリセットできます。
- 目標を達成すると、お祝いのメッセージが表示されます。
- 応援メッセージを表示し、見た回数を確認できます。
- 応援を見た回数は、確認メッセージ付きで0回に戻せます。

## 使い方

1. `index.html`をブラウザで開きます。
2. 今月の目標回数を変えたいときは、数字を入力して「目標を変更する」を押すか、Enterキーを押します。
3. 筋トレを行ったら、「筋トレを1回記録する」を押します。回数が1回増え、その日の日付が一覧に追加されます。進捗バーと達成率も更新されます。達成率は目標回数を超えても100%まで表示されます。
4. 日付の一覧では、筋トレを記録した日と、その日の記録回数を確認できます。
5. 今日の記録を取り消したいときは、「今日の記録を1回取り消す」を押します。確認メッセージでOKを選ぶと、筋トレ回数と今日の日付の記録が1回減ります。今日の日付の記録が0回になると、その日付は一覧から消えます。
6. 今日の記録がないときは、取り消しボタンを押せません。
7. 新しい月の記録を始めるときは、「今月の記録をリセットする」を押します。確認メッセージでOKを選ぶと、筋トレ回数と日付一覧がリセットされます。
8. 「今日の応援を見る」を押すと、応援メッセージが表示されます。応援回数を0回に戻すときは、「応援を見た回数を0回に戻す」を押します。

## 保存されるデータ

このページは、ブラウザの`localStorage`を使って次の情報を保存します。

- 筋トレの記録回数
- 今月の目標回数
- 筋トレを記録した日付と、その日の記録回数
- 応援メッセージを見た回数

保存された情報は、このパソコンのこのブラウザ内だけに保存されます。別のパソコンや別のブラウザには自動で共有されません。

「今月の記録をリセットする」を実行すると、筋トレ回数は0回になり、日付一覧は空になります。目標回数と応援回数は残ります。

## Gitでの基本的な確認方法

変更があるか確認するには、次を実行します。

```bash
git status
```

変更内容を確認するには、次を実行します。

```bash
git diff
```

保存済みの履歴を確認するには、次を実行します。

```bash
git log --oneline
```
